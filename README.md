# SlopZooka

**Coding agents. All over your room.**

Run Codex, Claude Code, OpenCode, and regular shells in Apple Vision Pro, with live web previews right beside them. Your Mac does the work. You arrange the chaos.

Apparently one screen full of agents wasn't enough.

- **Spread out.** Put terminals and previews wherever you want. Each workspace gets its own Git worktree, so projects can run side by side.
- **See what they built.** Local web apps show up automatically. Open a preview next to the agent working on it.
- **Just say it.** Dictate a prompt, pause to think, then send. A keyboard works too.
- **Come back later.** Close a window or disconnect. Your sessions keep running on your Mac.

## Try it

You'll need a Mac and Apple Vision Pro on the same trusted local network. Build from source for now.

1. [Build and open the Mac app](docs/mac-companion.md#build-and-install). Install your favorite agent CLI on the Mac.
2. [Run the Vision Pro app from Xcode](docs/vision-pro.md#connect-to-your-mac).
3. Pair with the code on your Mac, pick a repository and an agent, and make yourself some room.
